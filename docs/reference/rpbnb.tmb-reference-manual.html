Random-Parameter Bivariate Negative Binomial Regression

Description

rpbnb.tmb estimates bivariate count-regression models with negative-binomial margins, equation-specific covariates, optional random coefficients, and simulated likelihood integration based on randomized Halton draws. Estimation uses Template Model Builder (TMB) for automatic differentiation and nlminb() for optimization.

Details

The two response equations may use different formulas. Dependence can be specified as Famoye/Sarmanov, independence, or a discrete copula. The fitting function returns an rpbnb_tmb_fit object with estimated coefficients, covariance information, TMB diagnostics, and the requested and realized thread counts.

Examples

library(rpbnb.tmb)

sim <- simulate_rpbnb_tmb(n = 20,
  beta1 = c("(Intercept)" = 0.2, x1 = 0.4),
  beta2 = c("(Intercept)" = 0.1, x1 = -0.3),
  dispersion = c(m1 = 0.4, m2 = 0.5), seed = 1)
ctrl <- rpbnb_tmb_control(n_cores = 1L)

# Not run during manual build:
# fit <- fit_rpbnb_tmb(y1 ~ x1, y2 ~ x1, data = sim$data,
#   draws = 20L, control = ctrl)
# summary(fit)

Fit a bivariate random-parameter negative binomial model

Description

Fits a maximum simulated likelihood model with two negative-binomial count margins. Random-coefficient distributions are integrated over Halton draws, while TMB supplies objective and derivative calculations.

Usage

fit_rpbnb_tmb(formula_1, formula_2, data,
              random_1 = NULL, random_2 = NULL,
              draws = 400L, seed = 1234L, start = NULL,
              dependence = "famoye",
              control = rpbnb_tmb_control(),
              poisson_1 = FALSE, poisson_2 = FALSE)

Arguments

formula_1, formula_2
Model formulas for the first and second count outcomes.
data
A data frame containing the outcomes and all variables named by both formulas. Incomplete rows for the modeled variables are omitted.
random_1, random_2
Random-coefficient specifications for each equation. Use NULL for fixed coefficients, an unnamed character vector for Normal random coefficients, or a named list of distribution specifications. Supported distributions are "normal", "lognormal", "uniform", and "triangular".
draws
Number of randomized Halton simulation draws. The default is 400L.
seed
Integer seed used while generating the Halton randomization.
start
Optional named or positional starting vector. Names must match the model's parameter names when supplied.
dependence
"famoye", "independence", or an object returned by copula().
control
A control object from rpbnb_tmb_control().
poisson_1, poisson_2
Logical flags fixing the selected margin at its Poisson-limit dispersion.

Value

An object of class rpbnb_tmb_fit. Important components include coef, vcov, se, logLik, nobs, npar, m1, m2, optimizer, sdreport, and parallel. The parallel component records the requested and realized TMB thread counts.

Details

For copula dependence, Poisson-limit margins are not supported. The fitting routine checks the random-coefficient names against their equation's model matrix and validates the allowed dependence specification before constructing the TMB objective.

Examples

sim <- simulate_rpbnb_tmb(n = 20,
  beta1 = c("(Intercept)" = 0.2, x1 = 0.4),
  beta2 = c("(Intercept)" = 0.1, x1 = -0.3),
  dispersion = c(m1 = 0.4, m2 = 0.5), seed = 1)

# Not run during manual build:
# fit <- fit_rpbnb_tmb(y1 ~ x1, y2 ~ x1, data = sim$data,
#   random_1 = "x1", draws = 20L,
#   dependence = "famoye",
#   control = rpbnb_tmb_control(n_cores = 1L))

See Also

rpbnb_tmb_control, copula, methods for fitted objects.

Simulate bivariate negative-binomial data

Description

Generates bivariate count data from a random-parameter negative-binomial process with equation-specific coefficients and a selected dependence mechanism.

Usage

simulate_rpbnb_tmb(n, beta1, beta2,
                   random_1 = NULL, random_2 = NULL,
                   dispersion = c(m1 = 0.5, m2 = 0.5),
                   dependence = "famoye", lambda = 0,
                   covariates = NULL, seed = NULL)

Arguments

n
Number of observations to generate.
beta1, beta2
Named coefficient vectors for the two equations. Each must include "(Intercept)".
random_1, random_2
Random-coefficient specifications in the same format accepted by fit_rpbnb_tmb(). Simulation requires a finite positive scale for each requested random coefficient.
dispersion
Named vector with positive m1 and m2 values.
dependence
"famoye", "independence", or a copula() object.
lambda
Famoye dependence parameter. The default zero produces independent draws.
covariates
Optional data frame. When omitted, required covariates are generated from standard Normal distributions.
seed
Optional integer seed.

Value

A list containing data, truth, realized coefficient matrices, fitted conditional means, and simulation settings.

Details

For the Famoye model, a nonzero lambda must lie inside the model's admissible bounds. Copula simulation uses the selected discrete CDF rectangle construction.

Examples

sim <- simulate_rpbnb_tmb(n = 20,
  beta1 = c("(Intercept)" = 0.2, x1 = 0.4),
  beta2 = c("(Intercept)" = 0.1, x1 = -0.3),
  dispersion = c(m1 = 0.4, m2 = 0.5),
  dependence = "independence", seed = 42)
head(sim$data)

Control parameters for rpbnb.tmb estimation

Description

Creates a validated control object for optimization, TMB verbosity, OpenMP thread requests, and Halton-draw burn-in.

Usage

rpbnb_tmb_control(iterlim = 500L, reltol = 1e-8,
                  print_level = 0L, n_cores = 1L,
                  halton_burn = 300L)

Arguments

iterlim
Maximum optimizer iterations.
reltol
Relative convergence tolerance passed to nlminb().
print_level
Nonnegative verbosity level used by the fitting process.
n_cores
One whole-number TMB/OpenMP thread request. The installed TMB DLL can realize fewer threads; inspect fit$parallel after fitting.
halton_burn
Number of leading Halton points discarded before simulation draws are used.

Value

An object of class rpbnb_tmb_control.

Examples

ctrl <- rpbnb_tmb_control(iterlim = 300L, n_cores = 1L)
ctrl$n_cores

Specify a dependence copula

Description

Constructs a copula specification for use as the dependence argument of fit_rpbnb_tmb() or simulate_rpbnb_tmb().

Usage

copula(family, par = NULL)

Arguments

family
One of "frank", "normal", or "kimeldorf".
par
Optional fixed family parameter. For the Normal family, |rho| < 1; for the Kimeldorf/Clayton family, theta > 0; and for Frank, the parameter must be finite.

Value

An object of class rpbnb_copula containing the selected family and optional parameter.

Details

With an unspecified parameter, the dependence parameter is estimated by the fitting routine. Use "independence" rather than a copula object when an independent model is required.

Examples

copula("frank")
copula("normal", par = 0.3)
copula("kimeldorf", par = 1.2)

Marginal effects for a fitted rpbnb.tmb model

Description

Computes average marginal effects (AME) or marginal effects at the mean (MEM). Continuous variables use derivatives of the integrated conditional mean; binary variables use discrete differences.

Usage

rpbnb_tmb_marginal_effects(fit, which = c("y1", "y2", "both"),
                            type = c("AME", "MEM"), vars = NULL,
                            include_intercept = FALSE, digits = 4L, ...)

Arguments

fit
An rpbnb_tmb_fit object.
which
Margin "y1", "y2", or "both".
type
"AME" or "MEM".
vars
Optional variable names to retain.
include_intercept
Whether to include the intercept row.
digits
Printed decimal places.

Value

A data frame for one margin or a named list of two data frames when which = "both".

Details

When a coefficient is random, the computation uses the model's stored simulation draws to integrate the conditional mean and derivative.

Examples

# Not run during manual build:
# rpbnb_tmb_marginal_effects(fit, which = "both", type = "AME")

rpbnb_tmb_elasticities.

Elasticities for a fitted rpbnb.tmb model

Description

Computes continuous elasticities and binary semi-elasticities from the same Monte Carlo integrated means used for marginal effects.

Usage

rpbnb_tmb_elasticities(fit, which = c("y1", "y2", "both"),
                        type = c("AME", "MEM"), vars = NULL,
                        include_intercept = FALSE, digits = 4L, ...)

Arguments

The arguments have the same meaning as for rpbnb_tmb_marginal_effects.

Value

A data frame for one margin or a named list of two data frames for both margins.

Details

For continuous variables, the reported quantity is x / E[Y] * dE[Y]/dx. For binary variables, the reported semi-elasticity is E[Y | x = 1] / E[Y | x = 0] - 1.

Examples

# Not run during manual build:
# rpbnb_tmb_elasticities(fit, which = "y1", type = "AME")

Methods for rpbnb_tmb_fit objects

Description

Standard methods expose fitted-model quantities and concise reporting for objects returned by fit_rpbnb_tmb().

Usage

print(x, ...)
summary(object, digits = 4L, ...)
coef(object, ...)
vcov(object, ...)
logLik(object, ...)
AIC(object, ...)
BIC(object, ...)
predict(object, ...)

Details

  • print() reports the likelihood, observation and parameter counts, realized TMB threads, dependence specification, and rounded coefficients.
  • summary() prints equation coefficients, random-coefficient scale summaries, dispersions, and dependence information when available from sdreport.
  • coef() returns the named parameter vector and vcov() returns the fitted covariance matrix.
  • logLik() attaches degrees of freedom and observation count; AIC() and BIC() use the stored log likelihood and parameter count.
  • predict() currently returns a coefficient-based object of class rpbnb_tmb_pred; it does not calculate new-data fitted means.

Examples

# Not run during manual build:
# coef(fit)
# vcov(fit)
# logLik(fit)
# AIC(fit)
# BIC(fit)

Model, dependence, and random-coefficient notes

Negative-binomial margins

Each equation has its own mean specification and NB2 dispersion parameter. Set poisson_1 or poisson_2 in fit_rpbnb_tmb() only for a requested Poisson-limit margin.

Dependence choices

"famoye" estimates a Famoye/Sarmanov dependence parameter subject to admissible bounds. "independence" omits the estimated dependence parameter. Copula specifications use Frank, Gaussian, or Kimeldorf/Clayton discrete-copula dependence.

Random coefficients

Random coefficients are equation-specific and their variable names must occur in the corresponding formula. An unnamed character vector requests Normal distributions. A named list can select Normal, lognormal, uniform, or triangular distributions; a lognormal specification may include sign = -1 or sign = 1.

Threading note. n_cores requests an OpenMP thread count for the loaded TMB DLL. The realized count can be lower on a given build or platform. Inspect fit$parallel$requested and fit$parallel$realized after fitting.
